# Product Brief: AI-Comic-Studio

## Executive Summary

AI-Comic-Studio（梦境AI短剧平台）是一个面向短剧工作室内部使用的 AI 驱动制作平台。它将剧本创作、分镜拆解、提示词生成、AI 图片生成、AI 视频生成整合到一条完整的流水线中。与橙星梦工厂、星月梦AI等市面平台不同，AI-Comic-Studio 的核心价值在于：工作室可以接入自有 API、完全掌控模型选择和成本，并根据团队实际工作流深度定制。当前团队 5 人，目标支撑规模扩展到几十人。

---

## Core Vision

### Problem Statement

短剧工作室在 AI 辅助制作中面临两层问题：第一层是工具碎片化——完整流程需要在 5-6 个平台间跳转（ChatGPT/Claude/DeepSeek/Gemini 写剧本和拆分镜，Nanobanana/即梦生成分镜图片，Seedance/Sora 生成视频）；第二层是现有一站式平台（橙星梦工厂、星月梦AI）虽然覆盖了全流程，但无法接入工作室自有的 API，模型选择受限于平台方，成本和质量不可控。

### Problem Impact

- **无法接入自有 API：** 现有平台封闭，工作室无法使用自己采购的模型服务，被迫接受平台提供的模型和定价
- **上下文反复丢失：** 跨平台跳转时需要重新描述角色外观、场景风格、故事背景
- **风格一致性难以保证：** 不同平台/模型生成的角色和场景风格不统一，需要大量返工
- **提示词工程门槛高：** 将分镜脚本转化为有效的图片/视频提示词本身是一项专业技能
- **项目管理混乱：** 素材散落在各个平台，版本管理困难
- **跨平台操作繁琐：** 碎片化操作极大降低生产效率，缺乏统一的后台来管理多个大模型和资源
- **团队扩展受限：** 缺乏统一平台导致新人上手成本高，工作流难以标准化

### Why Existing Solutions Fall Short

| 平台 | 优势 | 不足 |
|------|------|------|
| 橙星梦工厂 | 全流程覆盖，拥有小说版权上游优势 | 无法接入自有 API，模型选择受限 |
| 星月梦AI | 全流程覆盖，多提示词支持，用户提示词分享社区 | 无法接入自有 API，模型选择受限 |
| 自行组合工具 | 模型自由选择 | 工具碎片化，效率极低 |

核心矛盾：要么接受平台限制换取流程便利，要么保留模型自由但忍受碎片化。没有一个方案能同时解决这两个问题。

### Proposed Solution

AI-Comic-Studio 作为工作室自有的内部制作平台，提供：

1. **剧本创作/导入** — 支持 AI 辅助创作或导入已有剧本
2. **智能分镜拆解与提示词生成** — AI 将剧本一步拆分为带完整提示词的分镜表（图片提示词+视频提示词），支持手动调整拆解结果，保留创作者对叙事节奏的控制；跨模型提示词格式自动转换
3. **角色一致性管理** — 角色视觉特征锁定机制，参考图/生成图绑定后自动传递到所有相关分镜
4. **团队提示词知识库** — 团队成员调优的提示词自动沉淀，标注适用场景（古装/现代/科幻）、适用模型、效果评分；新人直接从知识库选用
5. **分镜图片生成** — 调用自有 API 接入的图片模型（Nanobanana、即梦等）；支持同一提示词多模型对比生成
6. **分镜视频生成** — 调用自有 API 接入的视频模型（Seedance、Sora 等）；支持批量任务队列、失败自动重试
7. **平台内粗剪预览** — 生成的视频片段可在平台内拼接预览，快速查看粗剪效果
8. **统一后台管理** — 自主管理所有大模型 API Key、项目资产和团队资源
9. **项目仪表盘** — 全局进度追踪、API 调用成本统计、团队产出可视化
10. **权限管理** — 按角色分配权限（编剧/美术/视频/管理），支持团队从 5 人扩展到几十人
11. **后端服务层** — 新增后端服务做 API 代理（保护 API Key 不暴露在前端）、任务队列管理、文件存储；设计统一的模型适配抽象层，新模型只需编写适配器接入

### Key Differentiators

- **自有 API 接入 + 模型适配层：** 统一抽象接口代理所有模型调用，新模型只需写适配器，API Key 安全存储在后端，降低维护成本
- **模型自由切换 + 对比生成：** 同一提示词可同时发送多个模型，对比选择最佳结果
- **上下文贯穿 + 角色一致性锁定：** 角色视觉特征在整个流程中自动传递，解决跨分镜角色不一致的行业痛点
- **一步出分镜：** 分镜拆解与提示词生成合并为一步，减少流程等待
- **团队知识沉淀：** 提示词知识库让经验可复用，降低新人上手成本
- **批量生产能力：** 任务队列 + 失败重试 + 平台内粗剪预览，支撑规模化生产
- **内部深度定制：** 工作流完全按工作室实际需求设计
- **团队可扩展：** 项目仪表盘 + 权限管理 + 成本追踪，从 5 人到几十人平滑扩展

### 实施分期

- **P0（核心流水线）：** 后端服务 + 剧本导入 → 分镜拆解+提示词一步生成 → 接入1-2个图片模型 → 接入1-2个视频模型
- **P1（体验增强）：** 角色一致性锁定、提示词知识库、多模型对比、批量任务队列
- **P2（团队管理）：** 项目仪表盘、权限管理、成本统计

## Target Users

### Primary Users

**角色 A：全流程制作者 — 老手**
- 背景：工作室核心成员，熟练掌握全流程，每天产出约1分钟成片
- 日常工作：调提示词 → 盯图片生成 → 做视频，独立完成整个项目或分集协作
- 工作模式：异步并行推进多个分镜——有的在调提示词，有的在等生成，有的在检查结果
- 模型偏好：根据个人经验选择不同模型，对各模型的优劣有自己的判断
- 核心挫败感：AI 生成不了脑子里想要的画面，或遇到 AI 难以生成的场景
- 核心需求：快速试错（多模型对比、一键微调重新生成、历史记录回溯）、一个平台完成全流程
- 额外角色：调优的提示词和经验沉淀到知识库，带动新人成长
- 成功标志："一个平台全搞定，调好的提示词自动存下来"

**角色 B：全流程制作者 — 新手**
- 背景：新加入工作室，正在学习全流程，产出效率低于老手
- 日常工作：同老手，但依赖平台自动生成的提示词
- 核心痛点：对生成结果不满意时不知道怎么调优
- 核心需求：直接使用平台自动生成的提示词，开箱即用
- 成功标志："平台自动生成的提示词直接能用，我不用自己写"

### Secondary Users

**角色：工作室负责人（M）**
- 背景：既是制作者也是管理者，同时负责剧本创作/寻找
- 管理职责：分配任务、审核成片质量、控制 API 调用成本
- 核心需求：在做好自己制作工作的同时，能快速看到团队全局状态
- 成功标志："一眼看到每个人今天做到哪了，这个月 API 花了多少"

### User Journey

1. **开始工作** — 登录平台，进入负责的项目，看到分镜列表和各自状态（待处理/生成中/已完成/失败）
2. **拿到剧本** — 负责人已导入剧本并分配，制作者看到一步生成的分镜表+提示词
3. **调整提示词** — 新手直接使用平台自动生成的提示词；老手根据经验微调，调优后的提示词沉淀到知识库
4. **提交生成** — 选择模型提交图片生成，不等待，继续处理下一个分镜的提示词
5. **检查结果** — 收到通知后回来检查，不满意则微调重试或切换模型对比
6. **处理失败场景** — AI 实在生成不了的，手动上传外部制作的素材，不打断流水线
7. **生成视频** — 基于满意的分镜图片生成视频片段，同样异步处理
8. **预览交付** — 平台内粗剪预览，确认后标记完成

## Success Metrics

### 核心指标

| 指标 | 当前基线 | 目标 | 衡量方式 |
|------|---------|------|---------|
| 人均日产能 | 1分钟成片/人/天 | 2分钟成片/人/天 | 平台内统计每人每日完成的成片时长 |
| 人物/场景调优耗时 | 占全流程最大比例 | 显著缩短 | 从提交生成到确认满意的平均时间和轮次 |

### 流程效率指标

- **跨平台跳转归零：** 全流程在一个平台内完成，不再需要在多个工具间切换
- **人物/场景选型效率：** 通过多模型对比生成、角色一致性锁定、提示词知识库，减少"找到适合市场和剧本的人物/场景"的试错轮次
- **分镜到提示词的自动化率：** 剧本导入后，AI 一步生成分镜+提示词的覆盖率（目标：80%以上的分镜提示词可直接使用或仅需微调）

### Business Objectives

- **3个月目标：** P0 核心流水线跑通，团队5人全部迁移到平台内工作，人均日产能从1分钟提升到1.5分钟
- **6个月目标：** P1 体验增强上线，人均日产能达到2分钟，新人借助平台自动生成的提示词可更快进入产出状态
- **12个月目标：** P2 团队管理上线，支撑团队扩展到几十人，API 成本可追踪可优化

### Key Performance Indicators

| KPI | 目标值 | 说明 |
|-----|--------|------|
| 人均日产能 | ≥2分钟成片 | 核心北极星指标 |
| 人物/场景确认轮次 | 较当前减少50% | 从生成到满意的平均重试次数 |
| 平台内流程完成率 | 100% | 全流程无需跳转外部工具 |
| 分镜提示词可用率 | ≥80% | AI 自动生成的提示词可直接使用或仅需微调 |

## MVP Scope

### Core Features (P0)

**1. 后端服务层**
- API 代理服务，保护 API Key 不暴露前端
- 统一模型适配抽象层
- 用户认证系统（多用户登录）
- 数据库存储（项目、分镜、素材、用户）

**2. 剧本导入**
- 支持 txt 和 docx 格式导入
- 剧本内容展示和编辑

**3. 智能分镜拆解与提示词一步生成**
- 剧本导入后 AI 自动拆分为分镜表
- 同时生成每个分镜的图片提示词和视频提示词
- 支持手动调整分镜拆解结果和提示词

**4. 图片生成（接入2个模型）**
- Nanobanana API 接入
- 即梦 API 接入
- 用户可选择模型提交生成
- 异步生成，状态可见（待处理/生成中/已完成/失败）

**5. 视频生成（接入2个模型）**
- Seedance API 接入
- Sora API 接入
- 基于分镜图片+提示词生成视频
- 异步生成，状态可见

**6. 前端改造**
- 保留现有 UI 风格和整体设计
- 对接后端 API 替换所有模拟数据
- 真实登录系统替换假登录
- 分镜列表展示异步任务状态

### Out of Scope for MVP

- AI 辅助剧本创作（P1+）
- 角色一致性锁定机制（P1）
- 提示词知识库（P1）
- 多模型对比生成 / 同一提示词同时发多个模型（P1）
- 批量任务队列（P1）
- 平台内粗剪预览（P1）
- 项目仪表盘 / 进度追踪 / 成本统计（P2）
- 权限管理 / 角色分配（P2）
- 手动上传替代素材（P1）

### MVP Success Criteria

- 团队 5 人全部迁移到平台内工作，不再需要跳转外部工具完成核心流程
- 剧本导入 → 分镜+提示词 → 图片生成 → 视频生成的完整链路跑通
- 4 个模型（Nanobanana、即梦、Seedance、Sora）全部可正常调用
- 人均日产能从 1 分钟提升到 1.5 分钟

### Future Vision

- **P1（体验增强）：** 角色一致性锁定、提示词知识库、多模型对比、批量任务队列、平台内粗剪预览、手动上传替代素材、AI 辅助剧本创作
- **P2（团队管理）：** 项目仪表盘、权限管理、成本统计，支撑团队扩展到几十人
- **长期愿景：** 随着 AI 模型能力提升，持续接入更多模型，逐步提高自动化率，目标让平台成为工作室的核心生产基础设施
